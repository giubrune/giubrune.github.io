The COSMIC module links HYDRUS-1D to the COSMIC operator, which calculates the neutron counts a cosmic-ray neutron sensor would measure from simulated soil moisture profiles. Neutron count data can then be used directly in the inverse estimation of soil hydraulic properties.

The information content of cosmic-ray neutron data for this purpose is analysed in *Vadose Zone Journal* (2019).
