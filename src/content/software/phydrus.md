pHydrus is a Python package for working with HYDRUS from Python scripts and Jupyter notebooks. It can build model input files, run simulations, and read the results back for analysis and plotting. This makes HYDRUS easier to use in reproducible workflows, such as sensitivity analysis, calibration, and Bayesian inference, and in teaching (for example, *Soil Physical Modeling with Python* at BOKU).

See the documentation for installation instructions and examples.
